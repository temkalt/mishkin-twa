# 🕯 MISHKIN — Telegram Web App (TWA)

Это приложение представляет собой полноценный интернет-магазин ароматических свечей ручной работы, интегрированный прямо в Telegram (Telegram Mini App). 

Проект разделён на две основные части: **Frontend** (клиентская часть в Telegram) и **Backend** (серверная часть + база данных).

---

## 🛠 Технологический стек

### 🎨 Frontend (Клиентская часть)
Фронтенд отвечает за красивый интерфейс, плавные анимации и взаимодействие с пользователем внутри Telegram.
- **Ядро:** React 18 + TypeScript.
- **Сборщик:** Vite (обеспечивает молниеносную сборку и HMR при разработке).
- **Стилизация:** Tailwind CSS (utility-first подход для быстрой и консистентной стилизации).
- **Анимации:** Framer Motion (отвечает за премиальные переходы, `layoutId`-анимации, жесты и появление элементов).
- **Управление состоянием (State Management):** Zustand (легковесная и быстрая замена Redux, используется для корзины `useCartStore`, товаров `useProductStore` и пользователя `useUserStore`).
- **Роутинг:** React Router DOM (навигация между страницами без перезагрузки: Главная, Каталог, Корзина, Заказы, Админка).
- **Интеграция с Telegram:** Прямая работа с `window.Telegram.WebApp` (управление кнопками MainButton / BackButton, тактильная отдача HapticFeedback, цветовые темы).

### ⚙️ Backend (Серверная часть)
Сервер находится в папке `server/` и отвечает за логику корзины, создание заказов, панель администратора и промокоды.
- **Ядро:** Node.js + Express (REST API).
- **Язык:** TypeScript.
- **База данных:** PostgreSQL (реляционная БД для хранения товаров, заказов, пользователей и промокодов).
- **ORM:** Prisma (удобный инструмент для работы с БД, миграций и строгой типизации моделей).
- **Валидация данных:** Zod (для проверки входящих запросов).
- **Деплой:** Настроен `Dockerfile` для контейнеризации бекенда и `nginx.conf` для проксирования запросов и раздачи статики.

## 🌟 Ключевые особенности (Фичи)

### 1. Премиальный UX/UI
Проект фокусируется на максимальной плавности:
- **Shared Layout Animations:** При клике на товар в каталоге, картинка плавно "перелетает" на страницу товара.
- **Shimmer Skeletons:** Во время загрузки данных пользователи видят красивую переливающуюся анимацию, а не пустой экран.
- **Stagger Effects:** Элементы появляются каскадом (один за другим).
- **Микро-взаимодействия:** Тактильная отдача (Haptic Feedback) при добавлении в корзину, пружинящие анимации навигации.

### 2. Полная интеграция с Telegram
- **MainButton:** Основная кнопка Telegram используется для оформления заказа и добавления в корзину (она фиксируется внизу экрана и выглядит нативно).
- **BackButton:** Заменяет стандартную кнопку "назад", делая навигацию внутри TWA естественной.
- **Темизация:** Поддержка цветовой схемы устройства пользователя (Dark Mode / Light Mode).

### 3. Панель Администратора (Admin Panel)
Прямо внутри TWA встроена админка (доступна только пользователям с флагом `isAdmin` в БД).
- Просмотр статистики продаж.
- Добавление, редактирование и удаление товаров.
- Управление промокодами.
- Просмотр и смена статусов заказов (Новый, В обработке, Отправлен и т.д.).

### 4. Оптимизация
- **Lazy Loading (`React.lazy`):** Страницы загружаются частями только тогда, когда пользователь на них переходит. Это ускоряет первоначальный запуск.
- **Авторизация без боли:** TWA автоматически аутентифицирует пользователя по его Telegram ID при старте.

## 🚀 Деплой и сборка

1. **Frontend:** Собирается через команду `npm run build` (генерирует статичные файлы в папку `dist/`). Эти файлы могут раздаваться через Nginx, Vercel или любой другой хостинг.
2. **Backend:** Работает как Node.js сервис (порт `3000`). База данных PostgreSQL может быть поднята через Docker или использован облачный провайдер (например, Supabase / Render). 
3. **Nginx:** Служит прокси-сервером: направляет запросы к `/api/*` на бэкенд, а остальные запросы отдаёт статикой (фронтенд).
